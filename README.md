# Dialup Club Bubble

欢迎光临 Dialup Club (•ᴗ•)

这里放着一套老 iPhone「信息」的聊天气泡，就是 iOS 4、iOS 5 那几年，带小尾巴、亮晶晶、像果冻一样的那种。我们把它做成了一层可以披在聊天前端上的「皮」，希望你和屏幕那头的 TA 聊天的时候，能多一点千禧年的心情。

用之前，有几件小事想先跟你说一声：

- 它只负责好看。模型、后端、聊天记录，还是由你自己的前端来管，这里都没有。
- 所以需要你先有一个自己的聊天前端（在你自己的网址、自己的设备上），再把这层皮披上去。
- 它不会替你发任何网络请求。你选的颜色、壁纸，都只留在你自己的浏览器里，可以放心用。

## 里面有什么

- **气泡**：带尾巴、带光泽的老 iPhone 气泡；同一个人连发的几条只有最后一条有尾巴；整段括号里的动作显示成一行灰色小字。
- **气泡颜色**，「我」和「对方」分别选：
  - 自带两套原色：**iMessage**（蓝）、**Classic**（绿）；
  - 一组色卡 **Millennium**，17 个颜色，千禧年和 Aero 的味道；
  - **Custom**：从色谱里自己挑任意颜色（iPhone / Mac 的 Safari 里弹出来的是系统自带的取色器）。
- **Opacity**：一根滑杆调气泡的透明度，默认不透明。
- **Wallpaper**：自带六张千禧味的壁纸，点一下就换；也可以从自己设备里挑一张图。自己挑的图只存在你这台设备的浏览器里，不上传到任何地方。
- **聊天方式**开关：「发短信 / 在身边」。它只负责记住你的选择，要配合你自己的提示词才有效果（见 `AGENTS.md`）。
- **顶栏和输入条**：老 iPhone 的蓝灰导航条、圆角输入框和「发送」键；还有 iOS 5 样子的设置页。这几样可以不要，只披气泡。

气泡、顶栏、输入条、设置页全部是 CSS 和内嵌 SVG 画的，没有用图片。仓库里唯一的图片是 `skin/wallpapers/` 里那六张自带壁纸，来源见同一文件夹里的 `来源.txt`。

## 先看看长什么样

下载后双击 `index.html`。那是一副演示用的骨头，示例对话是写死的，没有接任何模型。右上角「设置」里可以换颜色、调透明度、换壁纸。

## 怎么装到自己的前端上

把这个仓库的链接发给你自己的 AI，跟它说：

> 请阅读这个仓库里的 AGENTS.md，照着里面的步骤，把这套气泡皮肤装到我的聊天前端上。先把你找到的对照表给我看，再动手。

`AGENTS.md` 是专门写给 AI 看的安装说明。`examples/plain-chat/` 里有一个装之前（`before.html`）和装之后（`after.html`）的完整示范。

| `skin/` | 皮本身：`ios4.css`（气泡，核心）、`ios4-bars.css`（导航条和输入条，可选）、`ios4-settings.css`（设置页和选色页，可选）、`bubble-colors.js`（色卡和画法）、`bubble-settings.js`（设置界面的逻辑和接口） |

| `index.html`、`demo/` | 演示用的骨头，不属于皮 |

## 换一份色卡

色卡只有一张表，在 `skin/bubble-colors.js` 里：

```js
var BUBBLE_COLORS = {
  lipgloss: ["Lip Gloss", "f78ddb"],
  // 想加颜色就添一行：id: ["显示的名字", "六位色值"]
};
```

整颗气泡（中间亮、颜色聚在边缘一圈、顶上的白高光、带颜色的投影）是由这一个基准色自动算出来的，自选色走的也是同一套算法。

## 来源

- `demo/base.css` 的大部分规则，以及 `demo/chat.js` 里的一部分基础代码（文本转义和渲染、成组 / 尾巴的判断、设置页开关、输入框自动长高、键盘弹起处理），沿用自开源项目 Tidal_Echo（GitHub 上的 anhe2021212-spec/Tidal_Echo）的前端，取自 2026 年 7 月的版本。`index.html` 里聊天页、设置页的基本结构也来自它。
- `skin/` 里的东西是在那之上新写的。
- 界面模仿的是 Apple 早年 iOS「信息」和「设置」的外观；没有使用 Apple 的任何图片素材。本项目与 Apple 无关。
